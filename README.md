## 1. Project Description

This project aims to develop an e-commerce website using Amazon Web Services (AWS).

Customers can register, log in, view products, add products to their cart and place orders.

The main feature of this project is automatic server scaling. When more users visit the website, additional servers are added automatically. When traffic decreases, unnecessary servers are removed.

## 2. Problem Statement

During festival sales and special offers, the number of users visiting shopping websites increases suddenly.

This can make websites slow or unavailable. Running too many servers all the time can also increase costs.

Our project aims to solve this problem by automatically adjusting server capacity based on website traffic.

## 3. Objectives

- To develop a basic e-commerce website.
- To host the application on AWS.
- To automatically increase or decrease server capacity.
- To distribute user requests using a Load Balancer.
- To monitor server performance in real time.
- To use cloud resources efficiently.

## 4. Main Features

- User registration and login
- Product browsing
- Shopping cart
- Order placement
- Automatic server scaling
- Load balancing
- Real-time performance monitoring
- Admin monitoring dashboard
- Traffic simulation and testing

## 5. Technologies Used

- **Cloud Platform:** Amazon Web Services (AWS)
- **EC2:** Runs the application servers
- **VPC:** Provides the cloud network
- **IAM:** Manages access permissions
- **Application Load Balancer:** Distributes incoming traffic
- **EC2 Auto Scaling:** Automatically adjusts server capacity
- **CloudWatch:** Monitors server performance
- **CloudWatch Alarms:** Triggers scaling policies
- **S3:** Stores files and product images
- **RDS:** Stores application data

## 6. Expected Outcome

The project is expected to handle changes in website traffic more efficiently. It will reduce manual server management, improve application availability and help avoid unnecessary cloud resource usage.
